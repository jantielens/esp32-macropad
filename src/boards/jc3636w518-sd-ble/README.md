---
title: JC3636W518 SD BLE HID
description: SD-primary firmware with Bluetooth keyboard, mouse, and gamepad support.
---

Target `jc3636w518-sd-ble` enables BLE HID on the
[JC3636W518 SD-primary configuration](../jc3636w518-sd/README.md).
USB HID is disabled. BLE workload reliability needs physical validation.

Use the shared SD guide for card requirements, HID selection, and recovery,
and the [hardware guide](../jc3636w518/README.md) for board connections.
