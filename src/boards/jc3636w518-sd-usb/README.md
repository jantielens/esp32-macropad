---
title: JC3636W518 SD USB HID
description: SD-primary firmware with native USB keyboard, mouse, and gamepad support.
---

Target `jc3636w518-sd-usb` enables USB HID on the
[JC3636W518 SD-primary configuration](../jc3636w518-sd/README.md).
It preserves USB HID support previously provided by `jc3636w518-sd`.
BLE HID is disabled.

Use the shared SD guide for card requirements, HID selection, and recovery,
and the [hardware guide](../jc3636w518/README.md) for board connections.
