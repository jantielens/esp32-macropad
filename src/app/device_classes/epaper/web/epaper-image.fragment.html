Where the dashboard image is fetched from and how often the device wakes to refresh it. The device deep-sleeps between refreshes to save battery.

Image sources
When enabled, the device fetches a small <image-url>.crc32 sidecar before each refresh and skips the slow panel redraw when the image is unchanged. Leave off if your server does not publish CRC32 sidecars.
When enabled, rendered images are stored on the microSD card. On a later visit to the same image the device reads it from SD instead of downloading it again, cutting several seconds off the wake time. Requires an inserted microSD card.
