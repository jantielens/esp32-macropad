📷 Sensor Configuration

Sensor preset for capture measurements.

Sensor Preset
Select the sensor layout wired to this device. The 4-corner preset enables 2D capping and curtain twist analysis; the 3-line preset measures across the full frame; single-sensor measures at the position of sensor 1 only.
Sensor Offsets

Distance from the centre sensor (S2) to an outer sensor (S1 or S3) in mm. Used for capping gradient calculation.
