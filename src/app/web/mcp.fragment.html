💬 Sample prompts

Once the server is connected to your assistant, try asking it things like these.

  • "What's my device status?"
  • "How much free memory does the device have?"
  • "List the buttons on pad 0."
  • "List the buttons on the Lights pad." — pads can be referenced by their friendly name, not just their number.
  • "Switch to the info screen."
  • "Set the backlight to 40%."
  • "Add a button to pad 0 that shows the current time using a large font."
  • "Show MQTT topic home/temp as a bar chart on the Climate pad, ranged 0–40."
  • "Build a system-info pad: heap, CPU load, WiFi signal, and uptime as gauges."
  • "Rename pad 5 to Lights and add three buttons that publish MQTT toggles."
  • "On the Office Macropad, set the backlight to 30%." — name the device when several macropad MCP servers are registered; the assistant routes the request to that server.
  • "Compare free memory between the Office Macropad and the Living Room Macropad." — the device names come from each server registration / the device name set under Network.

Control prompts require the control toggle; authoring prompts require the pad authoring toggle above.
