Boot into OTA Mode

If firmware uploads are unreliable, use OTA mode to reboot with Bluetooth and MQTT temporarily disabled, freeing resources for the update. Bluetooth clients will disconnect and MQTT features will be unavailable.

After the device reconnects, return to this screen and upload the firmware. Your saved settings are unchanged. Reboot again to return to normal mode, even if the upload fails.

OTA mode is active. Bluetooth and MQTT will return after reboot.
