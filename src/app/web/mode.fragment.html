⚡ Operating Mode

Controls how the device runs.

Device runs continuously with display, touch, web portal, BLE, audio, and screen saver enabled. MQTT publishing is configured on the Network → MQTT page.
Device wakes from deep sleep, publishes to MQTT once, then sleeps again. Display, touch, web portal, BLE, audio, and screen saver are disabled in this mode. The publish interval on the Network → MQTT page is ignored — publishes happen once per wake.
Deep-sleep duration between wake cycles. 0 = wake immediately after each publish (~1 s).
Cap on exponential backoff when Wi-Fi connect fails. Uses the wake interval as the base.
Recovery Portal Auto-Sleep
Active only in Config / AP recovery mode (when Wi-Fi can't connect). After this many seconds of no portal activity, the device deep-sleeps for the same duration, then wakes to retry Wi-Fi. 0 = disabled (portal stays up indefinitely).
