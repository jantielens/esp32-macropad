Processing

Process existing and new notes using configured services when Wi-Fi is available. Recording always takes priority.

Transcription Service

Transcription sends recordings to Azure. Recording and playback work without either service.

Use the HTTPS resource root, not /openai/ or a project URL.
Leave blank to keep the saved key.

LLM Service

Title and summary generation sends saved transcripts to Azure. The deployment must support strict structured outputs.

Use the HTTPS resource root, not /openai/ or a project URL.
Leave blank to keep the saved key.
