cloud_downloadExternal Data

Fetch JSON sources for use in pad bindings.

Sources

Up to four sources. Each needs a unique name, URL, and refresh_seconds (1–86400; default 1800). Edit the JSON to change or rename a source; remove an entry to delete it.

Warning: Saved URLs are visible in the portal and configuration API; without portal authentication, anyone with access to the device can read them. Use HTTPS for external sources when possible and avoid using sensitive tokens or API keys.
