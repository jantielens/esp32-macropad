WiFi Network
Setup AP & Fallback

If this device cannot connect to its configured WiFi network during normal boot, it can create its own setup access point (AP). Connect to this network from your phone or computer to restore access, for example after changing your router or WiFi credentials. Set a password below to protect the setup network.

Choose Continue offline to disable this automatic AP fallback and start local features without network services instead. You can still start the setup AP using Restart into setup AP or the device's recovery procedure. First-time setup also remains available. This setting does not change runtime WiFi reconnection or duty-cycle behavior.

Shown in plain text so it can be shared. Leave empty for an open AP. Use 8-63 printable ASCII characters; changes apply the next time the setup AP starts.
