AP & Fallback

If this device cannot connect to its configured WiFi network during an online boot, it can create its own access point (AP). Connect from your phone or computer to restore access, for example after changing your router or WiFi credentials. The AP password below protects this recovery network.

Continue offline still tries WiFi first, then starts local features without network services if the connection fails. Unlike Offline operating mode, it does not skip WiFi startup. This fallback setting does not change runtime WiFi reconnection or duty-cycle behavior.

On devices that support Offline operating mode, WiFi and automatic AP fallback are not started when that mode is selected. Use the device's recovery procedure to open the AP or Config portal and change settings. Recovery and first-time setup remain available independently of the normal operating mode.
