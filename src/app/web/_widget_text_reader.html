Text reader
Enter text or a binding. To read full text from a source that supports it, use its binding token alone, with an optional fallback. Mixed text and other bindings use normal short values.
Font, size, metrics, alignment, and color. Always wraps; offsets and bitmap upscaling are not supported. Only color accepts bindings.
Paged only, when text overflows. Tap the upper/lower text half for the previous/next page, or swipe up/down, with or without these controls. There are no external navigation actions.
The reader owns touch input. Use separate buttons for actions. New text resets the reading position. Scrolling and paging are manual.
Position indicator
Shown when text extends beyond the viewport. Colors accept scalar bindings. Empty values use the device button background and foreground defaults.
