Customize the appearance of the boot, Wi-Fi setup, and info screens.

Appearance

These settings apply to the boot, Wi-Fi access point (AP) setup, and info screens. Changes take effect on the next boot; uploaded logos are selected when you save Appearance.

The setup and info screens show the selected logo when space permits.

Use a PNG or baseline (non-progressive) JPEG; progressive JPEGs are not supported. Images must be at most 1 MiB and 1,000,000 pixels. Transparent PNG pixels use the selected background color.
