Option selector
None sends every tap; Local remembers the last selection; Bound follows a state source.
Used in Bound mode. An unavailable source blocks taps. An unmatched fallback such as [var:a|unset] allows an initial selection but may mask an outage.
Options
Option selector colors
Group background fills the area behind all options. Option backgrounds add a separate fill behind each unselected option. Each uses its matching color; the selected option's background stays visible even when option backgrounds are off.
Selected foreground colors the label or monochrome icon; selected background fills the selected option. Individual option colors override shared and selected colors.
Option selector layout
Sets the height of the centered group and options as a percentage of the widget area. Touch targets stay full height.
Shrinks the visible option area on all sides, adding space between options. Touch targets stay the same size.
Sets the size of option labels. 0 = inherit the button's center-label font size.
Scales icons as a percentage of the available area after padding. 0 = fit the available area.
Adds space around each icon inside its option, making the icon smaller.
Small touch targets may be difficult to use.
Use {value} for the option ID, including inside quoted JSON strings.
