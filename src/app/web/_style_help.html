Label Style Reference

Override individual label styling with a compact key:value;... syntax.

Built-in bitmap font

Omit font to inherit the device family, or set font:@builtin to select Montserrat. Family and size inherit independently. Omit font_size for proportional sizing from the device base text size; an explicit size is absolute. Bitmap text selects the nearest compiled size: 12, 14, 18, 24, 32, or 36, with ties upward and endpoint clamping. font_upscale from 1.0 to 2.0 applies only to resolved bitmap text, including TTF fallback.

Uploaded TTF font

Set font to the uploaded font ID without .ttf. font_size accepts any positive integer pixel height from 1 to 65535, not just the bitmap sizes. Omit the size for automatic sizing. Do not use font_upscale; choose the desired pixel height instead.

If a font is clipped at the top or bottom despite enough button space, add font_metrics:bounds to calculate vertical metrics from the whole-font bounds. Alternatively use a multiplier such as font_metrics:2 or font_metrics:1.5 (1-65535). This adjusts vertical spacing and baseline, not glyph size or horizontal spacing. Omit it to keep the original metrics. Bitmap fonts ignore this option.

Missing or unloadable fonts, unsupported TTF builds, exhausted device cache capacity, and unrepresentable sizes or metrics fall back to the nearest bitmap size for the same resolved target. Device family and base text size changes require reboot.

Other style keys

align left, center, or right
y Vertical pixel offset (e.g. -2, 5)
mode clip, scroll, dot (...), or wrap
color Hex color (e.g. #FF0, #FF6600) or a binding, e.g. [expr:[net:any]?"#22c55e":"#94a3b8"]

Examples

font:my-font;font_size:40;font_metrics:bounds

TTF with automatic vertical correction

font:@builtin;font_size:36;align:left;mode:dot

Bitmap 36px, left-aligned, ellipsis

font:my-font;font_size:96

Uploaded TTF at 96px

font_size:14;color:#FF0

Small yellow text

y:-4;align:right

Shifted up, right-aligned

color:[expr:[net:any]?"#22c55e":"#94a3b8"]

Live color driven by a binding
