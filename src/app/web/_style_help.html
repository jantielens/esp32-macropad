Label Style Reference

Override individual label styling with a compact key:value;... syntax.

font_size Font size: 12, 14, 18, 24, 32, 36, or 48
font_family dseg7 (7-seg), bebas (condensed), doto (dot-matrix)
font_upscale Runtime font scale from 1.0 to 2.0 (e.g. 1.2, 1.4, 2)
align left, center, or right
y Vertical pixel offset (e.g. -2, 5)
mode clip, scroll, dot (...), or wrap
color Hex color (e.g. #FF0, #FF6600)

Examples

font_size:48;align:left;mode:dot Hero-sized, left-aligned, ellipsis
font_family:dseg7;font_size:48 7-segment LCD display font
font_size:14;color:#FF0 Small yellow text
y:-4;align:right Shifted up, right-aligned
