Idle Screen

Temporarily show a pad after inactivity, then return to the previous screen on activity.
Must be greater than 0, and shorter than Display Sleep when it is enabled.

Display Sleep

Fade to black, then put the display panel to sleep.
0 disables automatic sleep. Example: 1800 = 30 minutes.

Sleep Transition

Fade to black when Display Sleep begins. 0 = instant.
Fade from black when Display Sleep ends. 0 = instant.

Exit Standby and Wake

One touch fully exits Idle Screen or wakes Display Sleep. Only applies to touch-enabled boards.
An ON value fully exits Idle Screen or wakes Display Sleep, and keeps both stages off while it remains ON.
