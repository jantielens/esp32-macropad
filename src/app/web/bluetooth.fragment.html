Bluetooth is unavailable on this firmware.

Bluetooth Transmit Power

One device-wide setting for all supported Bluetooth features: BTHome button events, keyboard/mouse/gamepad HID, and sensor duty-cycle telemetry. It does not enable any of these features. Save stores the selected power; reboot to apply it. Current radio power stays unchanged until then.

Transmit power cannot be configured on this backend; the hosted co-processor controls radio power. Other Bluetooth features and event timing remain available.

Transmit power change pending reboot.

Higher power can improve range and reception but uses more energy. Lower power can save energy but may cause missed events or sensor updates and weaker HID connections.
BTHome Button Event Publishing

These timing controls affect BTHome button events only, not HID or sensor telemetry. Button numbers and event types remain configured in each action. No Bluetooth pairing is required. Save applies timing to the next event burst without reboot; a burst already running keeps its original timing.

Events are unencrypted and best-effort. A successful queue result does not confirm that Home Assistant received or executed the event. Do not use these events for security-sensitive operations. See the Home Assistant BTHome workflow.

100-1000 ms; default 350 ms. Longer bursts add reception opportunities but delay queued events. Duration must be at least three advertising intervals.
