Customize the boot screen and configure actions to run when the device boots.

Boot Screen

The status label displays boot progress, such as “Starting…”. The status font size and status text color fields style this label, while the background color styles the boot screen. Changes take effect on the next boot; uploaded logos are selected when you save Boot Settings.

The WiFi access point (AP) setup screen also uses these font and color settings. It shows the selected boot logo when space permits.

Use a PNG or baseline (non-progressive) JPEG; progressive JPEGs are not supported. Images must be at most 1 MiB and 1,000,000 pixels. Transparent PNG pixels use the selected background color.

Boot Actions

Run up to 3 actions in order each time the device boots. Save Boot Settings to save these actions and any boot-screen changes.
