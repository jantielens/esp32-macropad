List
Unique within the pad. Use this ID in List navigation actions.
Use [item:field|fallback] in row labels. Row label styles support font, font_size, font_metrics, align, and color. Position offsets (x, y) and font_upscale are ignored. Labels always use single-line ellipsis (mode:dot); bindings are supported only in color.
Item layout
0 = Auto; otherwise, number of visible items. Auto fits rows using label fonts; item height adjusts to fill the List.
Horizontal space between labels and item borders.
Vertical gap between items.
Scroll lets you swipe through items; Paged shows one page at a time without scrolling. Board default is Paged on interactive e-paper and Scroll otherwise.
Item appearance
Colors can use item or scalar bindings. Empty values use the device-wide button defaults.
Selected item appearance
Keep the activated item selected. Turn off for navigation Lists; item actions and press feedback still work.
Colors can use item or scalar bindings. Empty values inherit the row colors; the border uses an automatic default based on button defaults.
Position indicator
Shown when items extend beyond the viewport. Colors accept scalar bindings, not item bindings.
Use [item:field|fallback] in supported action fields to reference the activated item. To use its ID after navigation or a pause, first save [item:id] in a variable.
