text_fieldsTTF Fonts

Upload trusted, static, single-face TrueType (.ttf) fonts with TrueType outlines. Variable fonts, font collections, CFF/OpenType outlines, and WOFF/WOFF2 files are not supported.

In the pad editor, set a button label or widget's text style to font:my-font;font_size:32, using the uploaded font ID. Omit font_size for automatic sizing. Missing or unloadable fonts use the built-in bitmap fallback.

1-31 lowercase letters, digits, underscores, or hyphens. Files are stored under /fonts.

PSRAM: Each distinct TTF size or metrics setting needs a separate cached font instance. Reuse sizes and metrics settings where possible; many instances or very large sizes consume more PSRAM.
