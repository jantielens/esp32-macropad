Media features add images, typography, sound, and camera content to the device.
Some use uploaded files; others fetch content or use attached hardware.
Choose the corresponding task below for its capabilities and management tools.

## Choose a task

* [Upload images, configure a slideshow, or display a remote feed](images.md)
* [Install a font and choose device or label typography](fonts.md)
* [Set volume, feedback, alert sounds, and Music controls](audio.md)
* [Configure an attached camera, snapshots, and motion sensing](camera.md)
* [Install a trusted native Extension and place it in a button](extensions.md)

The corresponding portal section appears only when the installed firmware
supports it. A remote camera feed, an attached camera, and a local image
library are separate capabilities.

Uploads use the selected primary storage backend unless the feature describes
a separate executable slot. Check [capacity](../device/storage.md) and
[backup scope](../device/backup-and-restore.md) before deleting or replacing files.

For prepared images on a sleep-first device, use the
[E-Paper Frame workflow](../specialized/epaper-frame/README.md), not button-background
instructions.
