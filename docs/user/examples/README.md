Practical dashboards and controls combine layouts, live data, actions, and
external automation. The examples below show those pieces working together,
with explicit data contracts you can adapt to your own setup.

Each example assumes [basic setup](../getting-started.md) and links prerequisites.
Use your actual entities/topics/URLs. These are configurations to adapt, not
automatically installed templates.

* [Home energy](home-energy.md): balanced power gauge and history
* [Light controls](light-controls.md): toggle, state color, and brightness steps
* [Camera grid](camera-grid.md): several remote snapshot views
* [World clock](world-clock.md): independent timezones and typography
* [Server monitor](server-monitor.md): external telemetry versus local health
* [Climate control](climate-control.md): numeric steps with HA automation
* [HA alerts](home-assistant-alerts.md): doorbell, quiet hours, and dismissal
* [Frame wake archive](frame-wake-archive.md): record delayed/correlated events
