Specialized firmware adapts the device to a particular role, such as a sleeping
image frame, sensor, voice interface, or measurement instrument. These workflows
have their own setup and operating steps alongside shared device settings.

* [Choose an e-paper workflow](epaper.md): image-only Frame or interactive pads
* [E-Paper Frame](epaper-frame/README.md): connect an image source and schedule sleep
* [Interactive E-Paper](interactive-epaper.md): tune refresh for live pads
* [Sensor node](sensor-node.md): MQTT or BLE wake/publish/sleep operation
* [Voice Assistant](voice-assistant.md): transcription, response, and speech playback
* [Coffee Scale](coffee-scale/README.md): calibrate, brew, and review logs
* [Darkroom Timer](darkroom-timer/README.md): relay control, test strips, and print logs
* [Shutter Tester](shutter-tester/README.md): calibrate, capture, and interpret results

Features appear only on firmware that supports them.
Use [board-local notes](../hardware.md) for wiring, connectors, geometry,
physical controls, power limits, and hardware calibration values.
